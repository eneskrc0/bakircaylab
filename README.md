# Bakircay Lab

Bakircay Lab'ın biyosensör projelerini tanıtan site: saliva temelli stres takibi ve sütte antibiyotik kalıntılarının yerinde taranması.

Canlı adres: https://bakircaylab.com

Statik bir sitedir, derleme adımı yoktur. GitHub Pages bu deponun `main` dalının kök klasöründen yayın yapar. `CNAME` dosyası özel alan adını tanımlar.

- `index.html`: tek sayfa; Ana sayfa, `#biz-kimiz` ve `#amacimiz` bölümleri aynı dosyadadır.
- `public.css`, `theme.css`, `brand.css`: stiller (`brand.css` fontlar ve renkler).
- `theme.js`: açık/koyu tema ve TR/EN dil seçimi.
- `public.js`: sayfa geçişleri ve videolar.
- `media/`: videolar (her biri MP4 ve WebM olarak).
